TASK-1 DESCRIPTION


his Java program demonstrates file handling operations such as reading, writing, appending, modifying, and copying text files using standard Java I/O and NIO libraries.
It’s designed as a simple utility and learning reference for students or developers exploring Java file operations.

🚀 Features

✅ Create and write new text files
✅ Append new lines to existing files
✅ Read complete file contents
✅ Replace specific text in a file
✅ Insert a line at a specific position
✅ Delete lines containing a given keyword
✅ Copy files to a new location

🧠 Concepts Used

java.io.* and java.nio.file.*

BufferedReader and BufferedWriter

File reading/writing with UTF-8 encoding

Stream API for line filtering and replacement

Exception handling for file operations
